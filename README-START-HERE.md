# Graveyard Shift — Kiro starter kit

This is a **planning and configuration starter**, not a finished extension. No app source code, functional timer, original sprite art or test output is included. Use Kiro IDE to implement it and collect authentic development evidence.

1. Start a NEW public or private GitHub repo for this hackathon build, not an earlier project. Extract this kit into the repository root (including hidden `.kiro/`).
2. Open the repository in Kiro IDE. Review `.kiro/steering/` and `config/defaults.json`.
3. Open Kiro **Specs** and paste `docs/01-KIRO-FIRST-PROMPT.md`. Review/approve requirements, design and tasks generated by Kiro.
4. Ask Kiro to scaffold the extension with working npm scripts including `verify`. The `.kiro/hooks/verify-after-task.json` hook uses `npm run verify --if-present`, so until `verify` exists, it is a no-op. Verify hook enabled and running in your IDE.
5. Implement tasks one at a time; test the extension in Kiro IDE and packaging to `.vsix`.
6. Do manual usability checks and capture authentic screenshots, videos and test output. Never claim simulation is real five-hour observation.
7. Ensure public GitHub root `.kiro/`, LICENSE, open-source assets and `<3 min` public YouTube demo before submission.

The exact baseline config mirrors your provided JSON. `reducedMotion: true` intentionally suppresses elaborate effects for users with that setting; for visual demo, switch it off with consent and label any accelerated time simulation.

Use the included custom agents via the Kiro agent selector if your version supports them; the defaults are sufficient to begin. Powers and MCP are optional and should be installed only when they materially improve workflow. Do not give blanket automatic shell permissions.
