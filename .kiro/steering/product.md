# Graveyard Shift — product truth

Product: Graveyard Shift, a privacy-first developer wellness companion for Kiro IDE.
Tagline: Your code is alive. But are you?
Hackathon: Kiroween 2026 — Costume Contest.

## Problem and outcome
Developers can get immersed in work and overlook breaks. Our outcome is greater awareness of self-care while coding, not more hours worked or an inferred medical diagnosis.

## Core loop
IDE activity signals → configurable gentle reminders → user choice to break / snooze / dismiss → companion reacts → user-confirmed recovery.

## Product principles
- Take care of the human behind the code. Never gamify long coding sessions as achievements.
- Spooky visuals must communicate wellness state, not punish, shame, startle, or manipulate.
- Reminders are gentle, accessible, reversible, and configurable. Snooze is a legitimate choice.
- Avoid interrupting active typing when possible; ensure a maximum notification delay so reminders are not silently lost.
- No camera, microphone, account, cloud backend, code-content collection, or medical diagnoses for MVP.
- All user-facing text is natural English: calm, considerate, plainspoken, no exaggerated claims.
- Keep the project feasible, demonstrable, and testable before the competition deadline.

## Required experience
One coherent companion in the Kiro sidebar (Human → Tired → Infected → Zombie → Recovery). A long-session editor panel (The Last Human) can show a dramatic but non-blocking zombie moment when the user-defined threshold is reached. The user must be able to dismiss it, snooze it or take a break; never force OS-wide overlays or block code editing.
